# nexHarden — راهنمای خیلی ساده

**ابزار بررسی امنیت لینوکس**

این برنامه سیستم لینوکس شما را بررسی می‌کند و می‌گوید کدام تنظیمات امنیتی مشکل دارند.

---

## چی کار می‌کند؟

- سیستم را **فقط بررسی** می‌کند (چیزی را خراب نمی‌کند)
- مشکلات امنیتی را پیدا می‌کند
- یک گزارش زیبا می‌سازد
- به شما می‌گوید چه چیزی را باید درست کنید

---

## چطور نصب کنم؟

۱. فایل زیپ را باز کنید:
```bash
unzip nexHarden-1.0.0.zip
cd nexHarden
```

۲. اجازه اجرا بدهید:
```bash
chmod +x nexharden
```

تمام! نصب خاصی لازم نیست.

---

## چطور سیستم را بررسی کنم؟

ساده‌ترین دستور این است:

```bash
./nexharden audit
```

اگر می‌خواهید بررسی کامل‌تری انجام شود (توصیه می‌شود):

```bash
sudo ./nexharden audit --full
```

بعد از چند ثانیه، گزارش آماده می‌شود.

---

## گزارش کجاست؟ چطور ببینمش؟

گزارش‌ها داخل پوشه `reports` ساخته می‌شوند.

### روش ۱ (ساده‌ترین):
```bash
xdg-open reports/audit-*.html
```

### روش ۲:
اگر روش بالا کار نکرد:
```bash
firefox reports/audit-*.html
```

یا:
```bash
google-chrome reports/audit-*.html
```

---

## مشکلات رایج و راه حل آن‌ها

### ۱. خطای «Access to the file was denied» یا ERR_ACCESS_DENIED

**علت:** فایل گزارش با دسترسی محدود ساخته شده و مرورگر نمی‌تواند آن را بخواند.

**راه حل:**
```bash
sudo chown -R $USER:$USER reports/
chmod 644 reports/*.html reports/*.json
```

بعد دوباره باز کنید:
```bash
xdg-open reports/audit-*.html
```

---

### ۲. باز هم گزارش باز نمی‌شود

این روش تقریباً همیشه کار می‌کند:

```bash
cd reports
python3 -m http.server 8080
```

حالا در مرورگر این آدرس را باز کنید:

```
http://localhost:8080
```

روی فایل `audit-....html` کلیک کنید.

برای متوقف کردن سرور، کلیدهای `Ctrl + C` را بزنید.

---

### ۳. گفت Permission denied یا باید با root اجرا شود

بعضی بررسی‌ها نیاز به دسترسی مدیر دارند.

کافی است دستور را با `sudo` اجرا کنید:

```bash
sudo ./nexharden audit --full
```

---

### ۴. برنامه اصلاً اجرا نمی‌شود

این دستورات را امتحان کنید:

```bash
python3 --version
```

باید نسخه ۳.۹ یا بالاتر را نشان دهد.

اگر پایتون نصب نبود:
```bash
sudo apt update
sudo apt install python3
```

---

### ۵. گفت module not found یا خطای پایتون داد

مطمئن شوید داخل پوشه اصلی برنامه هستید:

```bash
cd ~/Downloads/nexHarden-1.0.0/nexHarden
./nexharden audit
```

---

## دستورات مهم (به زبان ساده)

| دستور | معنی |
|-------|------|
| `./nexharden audit` | سیستم را بررسی کن |
| `sudo ./nexharden audit --full` | بررسی کامل‌تر |
| `./nexharden system-info` | اطلاعات سیستم را نشان بده |
| `./nexharden version` | نسخه برنامه را نشان بده |
| `./nexharden history` | گزارش‌های قبلی را نشان بده |

---

## سخت‌سازی (Hardening) چیست؟

برنامه می‌تواند بعضی تنظیمات امنیتی را **پیشنهاد** دهد و در صورت تأیید شما اعمال کند.

**مهم:**
- به‌صورت پیش‌فرض فقط پیشنهاد می‌دهد و چیزی را تغییر نمی‌دهد.
- برای اعمال تغییرات باید خودتان تأیید کنید.

پیش‌نمایش (هیچ چیزی عوض نمی‌شود):
```bash
sudo ./nexharden harden --profile basic --dry-run
```

اعمال تغییرات (با تأیید شما):
```bash
sudo ./nexharden harden --profile basic --apply
```

---

## نکات خیلی مهم

- این برنامه **جایگزین آنتی‌ویروس یا فایروال نیست**.
- امتیاز بالا به معنای «کاملاً امن» بودن سیستم نیست.
- همیشه قبل از اعمال تغییرات، پیش‌نمایش را ببینید.
- گزارش‌ها ممکن است اطلاعات حساس داشته باشند؛ آن‌ها را با دیگران به اشتراک نگذارید.
